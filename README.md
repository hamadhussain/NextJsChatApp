# 🚀 Real-Time Messaging App

A full-stack real-time messaging application built with modern web technologies, enabling seamless communication with secure authentication and responsive UI.

---

## 🔥 Features

* 💬 Real-time messaging
* 🔐 Secure user authentication
* 👤 User session management
* ⚡ Fast and responsive UI
* 🌙 Clean and modern interface

---

## 🧠 Tech Stack

* **Frontend:** Next.js
* **Authentication:** Clerk
* **Real-time Messaging:** Stream Chat
* **Styling:** Tailwind CSS

---

## ⚙️ How It Works

* Users sign up/login using Clerk authentication
* Stream Chat handles real-time messaging and channels
* Messages are instantly synced across users
* UI updates dynamically using Next.js

---

## 📦 Installation

Clone the repository:

```bash
git clone <your-repo-link>
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:3000
```

---

## 🔑 Environment Variables

Create a `.env.local` file and add:

```
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_key
CLERK_SECRET_KEY=your_secret

NEXT_PUBLIC_STREAM_API_KEY=your_key
STREAM_SECRET_KEY=your_secret
```
